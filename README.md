# 赛博工牌（DeepSeek Harness 插件）

把 FoloToy AI Passport 变成一块工牌。这个插件负责在电脑上维护工牌内容，并同步到设备。

## 安装

1. 在 Harness 插件市场搜 `albis-aipassport-badge` 安装，或运行
   `dsh plugin --profile desktop add albis-aipassport-badge`，然后重启 Harness。
2. 设备刷入 FoloToy AI Passport 社区的「赛博工牌」玩法。
3. 在工牌首页长按 `▲` 进入蓝牙配网连好 2.4G Wi-Fi，屏幕出现 4 位配对码；Harness 插件页顶部出现同样的码，核对后点“允许”。

## 能做什么

工牌 V1.0 共四页，`OK` 下一页、`▼` 上一页，长按 `OK` 一键息屏：

- **工牌（对外展示）**：5 套风格 × 14 组色卡（`解压键帽 / 心情贴纸 / 潮流通行证 / 像素冒险 / 复古终端`），支持内置插画、像素精灵与自定义上传图片。按 `▲` 切换状态或心情贴纸。
- **名片码（一键扫码）**：最多 3 张社交二维码（微信 / 企微 / 小红书 / 钉钉 / 飞书），电脑端提取短链并纯黑白整数倍硬绘，65% 防反光背光；按 `▲` 切换名片。
- **待办便签（给自己看）**：最多 10 条队列 × 3 个重要星标，支持「职场简约 / 手账潮玩」双场景；短按 `▲` 向下移焦、长按 `▲` 标记完成（已完成自动沉底）。一分钟不按键自动回到工牌页。
- **摸鱼池**：不联网也能玩的解压小游戏（按 `▲` 下水与撒鱼食、`OK`/`▼` 戳鱼、吹气起风、长按 `OK` 上岸），战绩按天记到电脑上。

这个插件负责在电脑上维护这些内容：

- **编辑页**（`http://127.0.0.1:8797`）：1:1 像素级设备预览，涵盖 5 套风格 × 14 组色卡、内置插画/像素库、图片抠图上传、二维码图片解码验真与待办星标排序。
- **对话里维护**：在 Harness 对话里说“把状态换成开会中”“帮我记一下周五交周报”“换一套复古终端风格”，助手用 `badge_get`、`badge_update`、`badge_set_status`、`badge_memo` 完成。

工牌上切换的状态/心情、名片与划掉的待办也会自动同步回电脑。

NFC 暂时没做：AI Passport 背面是一张不通电的 NTAG213 标签，设备和电脑都写不了它，是否用于门禁要先确认门禁读卡器。

## 文件

| 文件 | 作用 |
|---|---|
| `index.js` | 入口：读设置、启动服务、注册对话工具 |
| `client.js` | Harness 侧边栏里的插件页 |
| `admin.html` | 工牌编辑页，地址 `http://127.0.0.1:8797` |
| `lib/profile.js` | 资料规则、发给设备的数据 |
| `lib/store.js` | 资料和设备数据的保存（`~/.dsh/cyber-badge/badge.json`） |
| `lib/server.js` | 给编辑页和设备用的接口；`/api/device/*` 要带设备令牌 |
| `lib/pairing.js` | 设备发现（UDP 8798）和配对 |
| `lib/tools.js` | 对话工具 |
| `lib/themes.js`、`lib/avatars.js` | 皮肤表（和固件一致）、预设头像 |
| `scripts/dev-server.mjs` | 不开 Harness 单独跑服务，开发用 |

## 设备怎么连电脑

设备和电脑在同一个 2.4G Wi-Fi 下。设备开机后广播找电脑，屏幕显示 4 位配对码；Harness 的插件页顶部出现同样的码和“允许”按钮，核对后点“允许”，设备拿到专属令牌。设备没联网时照常显示上次同步的内容，摸鱼池也能玩。

## 开发

```
npm test                              # 全部测试
node scripts/dev-server.mjs 8897      # 用临时数据跑服务
```

设备固件是 FoloToy AI Passport 社区的玩法「赛博工牌」，在官方社区页刷入即可；插件 1.0.x 对应固件 1.0.x。

字体：编辑页用得意黑 Smiley Sans（OFL-1.1，许可见 `assets/SmileySans-OFL.txt`）。
